# Tenants — per-company assets and configuration

Every folder here is scoped to exactly one tenant of the LAILIVE platform.
Nothing in this tree is a platform default; future tenants get their own folder,
their own brand assets, and their own document set. The administrator's company
(legacy-ai) is the first tenant, not the template for others.

Platform-level (cross-tenant) assets belong outside this tree and must not
inherit any tenant's marks, colors, voice, or templates.
